# 거지방 AI 총무 화면 명세

화면마다 무엇이 어떻게 놓이는지 적는다. 톤과 색은 DESIGN.md가 정하고 이 문서는 배치와 상태를 정한다.

화면 목록은 와이어프레임 v2(6화면) 기준이다. MVP 범위(9/1 회의)에 따라 화면이 빠지거나 합쳐질 수 있다. 라우팅 도구와 경로는 미정이다.

## 화면 목록

| id  | 화면           | 핵심 요소                                                                |
| --- | -------------- | ------------------------------------------------------------------------ |
| 1a  | 방 만들기      | 방 이름, 챌린지 강도 3단계(순한맛, 매운맛, 지옥맛), 초대 링크(최대 10명) |
| 1b  | 방 홈 피드     | 무지출 일수와 등급 헤더, 지출 인증 카드 피드(판결 말풍선), 하단 탭       |
| 1c  | 지출 인증      | 금액 크게 입력, 한 줄 설명, 사진(선택), 무지출 인증 별도 경로            |
| 1d  | 판결 결과      | 도장형 판결, 총무 코멘트, 등급 변동, 이의신청, 공유 CTA                  |
| 1e  | 주간 랭킹      | 무지출 일수 기준 순위, 내 순위 강조, 꼴찌 특별 편지 안내                 |
| 1f  | 공유 판결 카드 | 판결문 문서 컨셉(사건번호, 피고인, 죄목, 주문), 1080x1350, 1d에서 생성   |

확정된 UX 결정은 다음과 같다.

- 판결 태그는 승인(회색), 기각(빨강), 칭송(초록) 세 가지
- 무지출 인증은 1c에서 "또는" 구분선 아래 별도 버튼. 판결 없이 바로 칭송받는다
- 챌린지 강도 3단계에 각각 설명 문구가 붙는다. 순한맛 "웬만하면 승인, 가끔 한마디", 매운맛 "기각 기준 깐깐, 잔소리 기본", 지옥맛 "숨만 쉬어도 기각, 각오하세요"
- 판결에는 친구들 반응("참았어야지", "인정", "나도 샀음")이 함께 쌓인다

## 화면 상세

시안이 나온 뒤 화면마다 아래 절을 복사해 채운다.

### {화면 이름} `{id}`

**목적.** 이 화면에서 사용자가 이루는 일 하나를 적는다.

**구성.** 위에서 아래로 놓이는 요소를 순서대로 적는다.

**상태.** 로딩 중일 때와 비어 있을 때, 오류일 때 각각 무엇이 보이는지 적는다.

**인터랙션.** 터치를 먼저 적고 키보드 조작을 함께 적는다. 키보드만으로도 조작할 수 있어야 한다.
