# 떼거지 디자인 방향

서비스가 주는 인상과 그것을 만드는 규칙을 적는다. 화면별 배치는 DESIGN-SPEC.md에 있다.

기준은 팀 위키의 서비스 설계 문서와 Claude Design 파운데이션 시안(시안 D)이다. 토큰 정본은 `src/app/styles/theme/`이고 시안의 토큰 이름이 곧 코드 이름이다. 미결정(화면 폭, 사극 어미, 도장 형태, 로고 시안 선택, 도메인)은 `../product/ROADMAP.md`의 미결정 절에, 코드와 위키의 불일치(다크모드, 티어 순서, 문구 차이, 로고 팔레트)는 `../product/SPEC.md`의 확인 필요 절에 있다. 이 문서는 그 자리에서 미결정이라고만 적는다.

## 인상

크림색 바탕에 조선 엽전 컨셉. 로고는 귀엽게, 판결은 맵게.

- 크림 바탕에 테두리 없는 카드. 한지 텍스처와 붓글씨는 쓰지 않는다
- 판결 5종(유죄, 무죄, 동의, 기각, 각하)은 테라코타와 그린의 낙관 도장으로 찍힌다
- 주요 액션 하나에만 노랑 CTA를 쓴다
- 시스템 고딕에 굵기로만 위계를 준다

## 카피 톤

거지방 감성이다. 존댓말인데 신랄하고, 구체적 환산으로 찌른다. 판결 문구가 핵심 재미 요소라 딱딱하면 죽는다.

- 유죄: "지하철이 있었잖아요. 알람을 12개 맞추세요. 12,000원이면 편의점 도시락이 두 개입니다. 반성문 기대하겠습니다."
- 무죄: "밥은 먹어야죠. 다만 곱빼기는 사치였습니다."
- 무지출 인증: "3일 연속 무지출. 이 방의 유일한 희망입니다."
- 판결문 본문: "밥이 없었다는 건 변론이 아니라 자백입니다."
- 배심원 사유 프리셋 칩(S-14): "지하철이 있었잖아요", "라면은 900원", "이건 인정", "다음엔 도시락"
- 솔직 팝업(S-09b): 화자는 AI 판사. "저기요. 그럴싸한 이름 붙이지 마시고 솔직히 얘기하세요."

헤드라인 "네 이놈!" 같은 사극 어미를 쓸지, 강도(순한맛, 매운맛, 지옥맛)별로 어미를 바꿀지는 미결정이다.

색의 역할 규칙이다.

- 테라코타는 유죄와 기각과 수감, 경고(Alert와 예산 초과 게이지와 초과 글자)에 쓴다
- 그린은 무죄와 동의와 무지출에만 쓴다
- 각하 도장은 회색이다
- 탠은 아바타 바탕이다
- 노랑 CTA는 화면에서 주요 액션 하나에만 쓴다. FAB와 고정 CTA가 그 자리다

## 타이포그래피

Pretendard Variable이고 굵기로만 위계를 준다. 글꼴은 저장소에 두고 서빙한다(`src/app/styles/fonts/`의 dynamic subset 92조각). `unicode-range`로 나뉘어 있어 브라우저가 화면에 뜬 글자에 필요한 조각만 받고 `font-display: swap`이라 오기 전에는 시스템 고딕으로 보인다. 글꼴 스택은 `app/styles/theme/typography.css`의 `--font-sans`이고 Pretendard Variable 다음에 시스템 글꼴, Apple SD Gothic Neo, Malgun Gothic, Noto Sans KR 순서로 떨어진다.

타이포 단계는 `app/styles/theme/typography.css`의 `--text-*` 토큰이고 클래스 하나에 크기와 행간, 굵기, 자간이 함께 들어 있다. 크기를 `text-[44px]`처럼 직접 박지 않는다.

## 라운드와 그림자

- 카드는 테두리 없이 라운드 22. 텍스트 필드는 카드색에 라운드 16
- 버튼과 칩과 세그먼트는 pill. 뒤로가기 버튼은 36 원형 필
- 바텀시트는 화면 바탕색, 상단 라운드 24, 핸들 40 x 4, 배경 딤은 `scrim` 토큰(50%). 열고 닫힐 때 스프링으로 올라오고 내려간다

## 판결 도장

판결 결과 5종은 뱃지가 아니라 낙관 도장이다. 유죄와 기각은 테라코타, 무죄와 동의는 그린, 각하는 회색이다.

도장은 정사각에 `rounded-stamp`, 왼쪽으로 7도 기울임(`-rotate-7`), `shadow-stamp`, 글자는 `stamp-text` 색이다. 크기는 세 가지다.

| 자리      | 한 변 | 클래스      | 글자               |
| --------- | ----- | ----------- | ------------------ |
| 피드 카드 | 54    | `size-13.5` | `text-stamp-sm` 18 |
| 카탈로그  | 64    | `size-16`   | `text-stamp-md` 22 |
| 판결 결과 | 96    | `size-24`   | `text-stamp-lg` 32 |

애니메이션 규칙이다.

- 판결 결과 페이지(S-10)는 찍히기 전과 찍힌 후 두 상태다. 도장 자리를 누르면 도장이 크게 위에서 내려와 한 번 눌렸다가 제자리에 서고, 닿는 순간 효과음과 진동, 잉크 파문, 짧은 화면 흔들림이 함께 난다. 헤더 오른쪽에 효과음 토글이 있다. 실제 서비스에서는 이 낙하가 페이지에 처음 들어올 때 한 번 재생될 자리다
- 피드 카드(S-06)와 공유 카드(S-11)에서는 찍힌 도장 자국으로만 보인다. 피드에서 판결이 막 확정된 카드를 처음 볼 때 소형 도장이 한 번 찍히는 것은 아직 없다

도장 형태(원형, 결재형, 인장형)는 미결정이고 코드는 정사각 인장형이다.

애니메이션은 `motion`으로 넣었다. 값은 `src/shared/lib/motion.ts`에 모아 두었고 감속 곡선은 `--ease-base` 토큰과 같은 `cubic-bezier(0.2, 0.8, 0.2, 1)` 하나를 쓴다. 화면 전환은 24px 이동에 260밀리초, 목록은 아래에서 10px 올라오며 항목마다 45밀리초씩 늦고, 시트와 도장만 스프링이다. 누를 수 있는 것은 누르는 동안 `scale(0.97)`로 줄어든다(`pressable` 유틸리티). OS에서 동작 줄이기를 켠 사용자에게는 전환 없이 결과만 보인다. 효과음은 음원 파일 없이 Web Audio로 합성한다(`src/shared/lib/stampSound.ts`).

## 로고와 앱 아이콘

로고는 엽전 주머니(P3)다. 주머니에서 네모 구멍 엽전이 튀어나오는 모양이고 `src/shared/components/Logo.tsx`의 `LogoIcon`(viewBox 120 x 120)이 원본이다. 주머니 path 2개, 끈, 패치, 바느질, 엽전, 반짝임으로 이루어진다. 로고 시안 선택은 미결정이다.

| 부분      | 색      |
| --------- | ------- |
| 주머니    | #cfa96e |
| 선        | #5C4028 |
| 끈        | #8C6239 |
| 패치      | #B9834A |
| 엽전      | #f5d95c |
| 엽전 구멍 | #5C4028 |

로고 색은 화면 토큰과 별개라 다크에서도 바뀌지 않는다. 엽전 몸은 노랑 바탕 변형(앱 아이콘과 파비콘)에서만 #EFC24F이고 크림 바탕(컴포넌트 로고와 OG 타일)에서는 #f5d95c다.

워드마크는 로고 아이콘 옆에 고딕 900 "떼거지"다. 홈 헤더는 `text-wordmark` 22, 로그인 화면은 `text-display` 38이다. 크림 바탕에 `ink`, 테라코타 바탕에 `stamp-text`를 쓴다.

PNG는 로고 SVG를 rsvg-convert 같은 도구로 내보낸 결과물이고 저장소에는 결과물만 둔다. og.png의 글자는 시스템 고딕으로 렌더한 것이라 다시 만들면 글꼴이 달라질 수 있다. 로고 원본은 팀 위키의 로고 시안과 Claude Design 시안에 있다.

`index.html`은 title 떼거지, description, theme-color(라이트 #f4f0e7, 다크 #1c1512), favicon, apple-touch-icon, manifest, og:type과 og:title과 og:description과 og:image, twitter:card를 가진다.

OG 이미지는 1200 x 630 라이트 하나다. 바탕 #f4f0e7에 오른쪽 아래 노랑 원(불투명도 18%), 왼쪽에 크림 타일 300(라운드 76, 그림자) 안 로고 216, 오른쪽에 떼거지(88 / 900, 자간 -0.03em)와 "친구들이 내 지출을 재판합니다"(36 / 700, mute), 유죄 도장(104, red, -7도)이다. 다크 OG는 시안에만 있다.

도메인은 미결정이라 OG 이미지에 주소를 넣지 않았고 `og:url`과 canonical도 없다. `og:image`만 GitHub Pages 절대 주소다. 도메인이 정해지면 바꿀 자리는 `../release/RUNBOOK.md`의 도메인 절에 있다.

## 아이콘

UI 아이콘은 lucide-react다. 뒤로가기 ChevronLeft, 더보기 EllipsisVertical, 카메라 Camera를 쓴다. 자체 SVG는 `LogoIcon`뿐이고 홈 헤더와 빈 상태가 이것을 쓴다.

## 반응형

모바일 세로가 기준이다. 화면 폭은 393으로 정했다(콘텐츠 폭 353, 좌우 20). 와이어프레임의 360 x 800은 옛 값이다. 코드는 `--container-phone` 토큰으로 `max-w-phone`을 쓰고 `app/layouts/AppLayout.tsx`가 가운데 정렬한다. 좌우 여백은 각 화면이 `px-5`로 준다.

## 다크모드

다크를 제공한다. 색 토큰 13개와 `stamp-text`, `shadow`가 다크 값을 갖고 `kakao`, `kakao-text`, `gray`, `scrim`은 그대로다. 값은 `light-dark()`로 한 줄에 두 테마를 적고 `color-scheme`이 고른다. 같은 토큰의 값만 바뀌므로 컴포넌트에 `dark:` 변형을 쓰지 않는다. 기본은 시스템 설정을 따르고 마이페이지의 화면 모드에서 시스템, 라이트, 다크 셋 중에 고정할 수 있다. 고른 값은 `localStorage`에 남고 `index.html`의 인라인 스크립트가 첫 그림 전에 적용한다.
