# 거지방 AI 총무 디자인 방향

서비스가 주는 인상과 그것을 만드는 규칙을 적는다. 화면별 상세는 DESIGN-SPEC.md에 적는다.

소윤과 미현이 디자인 컨셉 시안을 각 2개씩(총 4개) 만드는 중이다. 시안이 정해지면 이 문서를 채우고 코드의 토큰 정본인 `src/shared/styles/globals.css`를 함께 고친다. 지금 보일러플레이트 화면은 Tailwind 기본 amber 계열을 임시로 쓴다.

## 인상

거지방 감성. 존댓말인데 신랄하고, 구체적 환산으로 찌른다. 1차 회의에서 누더기와 흐물거리는 폰트 같은 거지 감성 아이디어가 나왔고, 와이어프레임 v2는 개구(Gaegu) 손글씨체의 스케치 톤을 썼다. 최종 인상은 시안 4개에서 고른다.

## 카피 톤 가이드 (확정)

판결 문구가 핵심 재미 요소다. 딱딱하면 죽는다. 예문은 전부 와이어프레임 v2 원문이다.

- 기각: "지하철이 있었잖아요. 알람을 12개 맞추세요. 12,000원이면 편의점 도시락이 두 개입니다. 반성문 기대하겠습니다."
- 승인: "밥은 먹어야죠. 다만 곱빼기는 사치였습니다."
- 칭송: "3일 연속 무지출. 이 방의 유일한 희망입니다."
- 랭킹: "일요일 밤, 꼴찌에게는 총무님의 특별 편지가 발송됩니다."

## 색

판결 3종의 색은 확정이다. 역할 토큰 이름과 값은 시안이 정해진 뒤 `src/shared/styles/globals.css`에 정의한다.

| 역할       | 확정된 것 | 토큰 값 |
| ---------- | --------- | ------- |
| 승인       | 회색 계열 | 미정    |
| 기각       | 빨강 계열 | 미정    |
| 칭송       | 초록 계열 | 미정    |
| background | 미정      | 미정    |
| primary    | 미정      | 미정    |

## 타이포그래피

글꼴은 정해지지 않았다. 지금은 Tailwind 기본 시스템 글꼴 스택을 쓴다. 와이어프레임 v2의 개구체 같은 웹폰트를 쓰기로 하면 의존성 추가라 먼저 묻는다.

| 단계 | 크기 | 굵기 | 쓰는 곳 |
| ---- | ---- | ---- | ------- |

## 간격과 모서리

기본 간격 단위와 모서리 반경은 시안 뒤 정한다. 값은 Tailwind 토큰으로 정의하고 `p-[18px]` 같은 임의값을 클래스에 직접 박지 않는다.

## 반응형

모바일 세로가 기준이다. 방 피드와 인증, 판결 화면 모두 모바일 사용을 전제한다. 태블릿과 PC 폭의 배치는 DESIGN-SPEC.md에 화면마다 적는다.
