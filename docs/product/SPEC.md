# 거지방 AI 총무 기능 명세

기능이 정확히 어떻게 동작하는지 적는 문서다. 왜 만드는지는 PRD.md가 맡는다. MVP 범위가 확정되면 기능 상세를 채우고 이 안내 문단을 지운다. 구현하다 규칙이 바뀌면 이 문서를 먼저 고치고 코드를 맞춘다.

## 용어

프로젝트 고유 용어를 정의한다. 코드 식별자와의 대응은 구현하면서 채운다.

| 용어        | 뜻                                                                         | 코드에서 |
| ----------- | -------------------------------------------------------------------------- | -------- |
| 총무        | 지출을 판결하는 AI 캐릭터. 이름은 미정                                     |          |
| 판결        | 지출 신고에 총무가 내리는 결과. 승인, 기각, 칭송 세 가지                   |          |
| 승인        | 어쩔 수 없는 지출로 인정. 회색                                             |          |
| 기각        | 사치로 판정. 빨강. 신랄한 코멘트가 붙는다                                  |          |
| 칭송        | 잘 참았거나 무지출일 때. 초록                                              |          |
| 무지출 인증 | 오늘 0원을 신고하는 별도 경로. 판결 없이 바로 칭송받는다                   |          |
| 이의신청    | 기각에 사정을 말하면 총무가 재심하는 절차                                  |          |
| 챌린지 강도 | 총무의 잔소리 수위. 순한맛, 매운맛, 지옥맛 3단계                           |          |
| 방어 금액   | 지출을 참았을 때 절약한 것으로 기록되는 금액                               |          |
| 무지출 랭킹 | 무지출 일수 기준 주간 순위. 일요일 밤 꼴찌에게 총무의 특별 편지가 발송된다 |          |
| 거지왕 랭킹 | 많이 쓴 사람 순위. 무지출 랭킹과 함께 두 축이다                            |          |
| 판결 카드   | 판결문 문서 컨셉의 공유 이미지. 1080x1350 세로, 방 초대 링크 포함          |          |

## 동작이 확정된 규칙 (8/31)

- 지출은 자진 신고 기반이다. 금액과 한 줄 설명은 텍스트로 받고 사진은 선택이다
- AI 연동은 에이전트가 OpenAI API 스타일로 응답하고 백엔드(geoji-server)가 받는다
- 랭킹은 자진 신고와 판결 데이터로 계산한다

## 기능 상세

기능마다 아래 절을 복사해 채운다.

### {기능 이름}

**동작 규칙.** 정상 흐름을 순서대로 적는다.

**화면 흐름.** 어느 화면에서 시작해 어디로 가는지 적는다. 라우팅 도구는 미정이라 정해지면 경로 표기를 맞춘다.

**경계 조건.** 비어 있을 때와 실패할 때, 중간에 끊길 때 무엇이 보이는지 적는다.

**데이터.** 무엇을 어디에 저장하는지 적는다. API 규약은 백엔드(geoji-server)와 정한 뒤 채운다.
