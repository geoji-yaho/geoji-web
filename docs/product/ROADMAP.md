### API 연동 현황

서버 기준 커밋은 geoji-server `d0f9fd5`(2026-09-11)다. 데이터 층 규칙은 `CONTRIBUTING.md`의 데이터 층 절, 환경 변수와 개발용 토큰은 `../release/RUNBOOK.md`의 환경 변수 절이 정본이다.

## M4가 밀릴 때 덜어내는 순서

M4는 사흘뿐이다. 밀리면 이 순서로 덜어낸다.

1. 형 집행 추적 (P1)
2. 리액션 (P1)
3. 랭킹 (P1)

공유 카드와 PWA는 끝까지 남긴다. 공유 카드는 확산 채널이고 PWA는 플랫폼 전제 자체다. 9/18과 9/20 사이 이틀은 버퍼이고 기능 추가에 쓰지 않는다. 9/20 제출 이후 기능 배포는 없다.

## 미결정

기본값을 채우지 않고 결정 시점까지 비워 둔다. 팀 위키 결정 로그의 미결정 중 프론트엔드 구현에 걸리는 것이다.

| 항목                              | 결정 주체                  | 프론트엔드에 걸리는 것                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 클라이언트 상태 관리, 테스트 도구 | 프론트엔드                 | 미도입. 서버 상태는 TanStack Query 5가 맡으므로 전역 스토어가 필요해지는 화면 착수 전에 정한다                                                                                                                                                                                                                                                                                                                                                          |
| 화면 폭                           | 프론트엔드                 | 360 또는 393. 와이어프레임은 360, 하이파이와 공통 컴포넌트는 393                                                                                                                                                                                                                                                                                                                                                                                        |
