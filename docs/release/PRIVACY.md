# 개인정보처리방침

서비스에 게시하는 개인정보처리방침의 원본이다. 실제 서비스가 수집하는 것과 한 항목도 다르면 안 된다. 수집 항목이 있는 SDK를 넣을 때마다 이 문서를 같이 고친다.

아래 항목은 팀 위키의 MVP 스펙과 화면 구성 명세에서 뽑은 후보다. 구현이 확정된 항목만 게시용 본문으로 옮긴다. 후보라고 적힌 것은 아직 확정이 아니다.

## 게시 위치

화면 구성 명세에 링크 자리가 두 곳 있다. 로그인 화면(S-01) 하단의 이용약관과 개인정보처리방침 링크, 마이페이지(S-12) 설정 리스트의 약관과 개인정보처리방침 항목이다. 링크가 가리킬 URL은 미정이다.

게시 URL: 미정

계좌와 카드 연동은 하지 않으므로 금융 정보는 수집하지 않는다. 이메일은 수집하지 않는 것이 기본이고 수집하게 되면 항목에 추가한다. 판결 공유 카드에는 프로필 이미지를 넣지 않고 닉네임과 티어만 넣는다.

## 외부 처리 후보

지출 게시물과 배심원 사유는 AI 판결 생성에 쓰이므로 외부 AI API로 전송된다. 게시용 본문에는 처리 위탁으로 적는다.

| 대상                 | 무엇을 보내는가                                                                             | 상태                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| AI 판사 (Claude API) | 게시물(금액, 카테고리, 무엇을, 사유), 방 규칙, 잔소리 강도, 배심원 평결과 사유, 피고인 상태 | 후보. 기획서는 Claude 단독이고 AI 에이전트 구조 문서는 Grok 병행이라 확인 필요 |
| 카카오 로그인        | 로그인 요청과 계정 정보 수신                                                                | 후보. 카카오 단독은 확정, 구현은 M1                                            |
| 웹 푸시              | 브라우저의 푸시 서비스로 알림 전송. 구독 정보는 백엔드가 보관한다                           | 후보. M4                                                                       |

## 호스팅

프론트엔드는 GitHub Pages다. 백엔드 호스팅은 미정이다(규민 결정). 첨부 사진이 어디에 저장되는지도 백엔드와 함께 정한다.

## 게시용 본문

위 후보 표에서 확정된 것만 옮겨 게시한다. 시행일 이후에 내용이 바뀌면 개정 이력을 남긴다. 절 구성은 수집하는 항목, 이용 목적, 보관 기간, 제3자 제공, 사용하는 외부 SDK와 호스팅, 문의처, 시행일이다.

- 이용 목적: 지출 게시물과 배심원 사유는 AI 판결 생성과 방 안 공개에, 무지출 신고와 투표와 댓글은 거지력 점수와 랭킹 계산에, 푸시 구독 정보는 알림 전송에 쓴다
- 보관 기간: 기획서의 제안값은 탈퇴 뒤 30일 안에 파기이고 확정은 아니다. 판결이 확정된 게시물은 삭제할 수 없다는 규칙과 탈퇴 처리가 맞물리므로 함께 정한다
- 제3자 제공: AI API 제공사와 카카오, 푸시 서비스로의 전송은 처리 위탁으로 적는다
- 시행일: 게시하는 날을 `2026-09-20` 형식으로 적는다
