# 개인정보처리방침

서비스에 게시하는 개인정보처리방침의 원본이다. 실제 서비스가 수집하는 것과 한 항목도 다르면 안 되므로 수집 항목이 생기는 SDK를 넣을 때마다 이 문서를 같이 고친다. 아래 항목은 팀 위키의 MVP 스펙과 화면 구성 명세에서 뽑은 것이고 구현이 확정된 항목만 게시용 본문으로 옮긴다.

게시 URL은 미정이다. 링크 자리는 로그인 화면 하단과 마이페이지 설정 목록 두 곳이다.

## 수집 항목

| 항목                    | 내용                                                                                 | 수집 방법                          | 필수 여부                 |
| ----------------------- | ------------------------------------------------------------------------------------ | ---------------------------------- | ------------------------- |
| 카카오 로그인 계정 정보 | 카카오 계정 고유 ID, 닉네임, 프로필 이미지 URL                                       | 카카오 로그인 때 카카오에서 받는다 | 필수                      |
| 닉네임과 프로필 이미지  | 최초 로그인 때 카카오 계정에서 가져온다. 닉네임은 서비스 안에서 바꿀 수 있다         | 카카오 로그인, 마이페이지 변경     | 필수                      |
| 월 예산                 | 한 달 지출 상한 금액                                                                 | 온보딩과 예산 변경 화면 입력       | 선택 (건너뛸 수 있다)     |
| 지출 게시물             | 타입(돈 썼어요, 살까 말까), 금액, 카테고리, 무엇을, 사유, 사진, 일시                 | 지출 등록 화면 입력                | 필수 (사유와 사진은 선택) |
| 배심원 투표             | 평결(유죄, 무죄, 동의, 기각)과 판결 사유 텍스트. 사유는 판결 확정 후 피고인에게 공개 | 배심원 투표 화면 입력              | 투표할 때 필수            |
| 댓글과 리액션           | 댓글 텍스트(최대 200자), 이모지 리액션 6종                                           | 피드와 판결 결과 화면 입력         | 선택                      |
| 무지출 신고             | 오늘 0원 썼어요 신고 일자와 취소 기록                                                | 홈 버튼                            | 선택                      |
| 거지방 정보             | 방 이름, 방 규칙, 잔소리 강도, 투표 마감 시간, 멤버 관계                             | 방 만들기와 초대 수락              | 방에 참여하면 필수        |
| 푸시 구독 정보          | 브라우저가 발급한 Web Push 구독 정보(엔드포인트와 키)                                | 알림 허용 때 브라우저에서 받는다   | 선택                      |

계좌와 카드 연동은 하지 않으므로 금융 정보는 수집하지 않는다. 이메일은 수집하지 않는 것이 기본이고 수집하게 되면 항목에 추가한다. 판결 공유 카드에는 프로필 이미지를 넣지 않고 닉네임과 티어만 넣는다.

## 외부 처리

게시용 본문에는 처리 위탁으로 적는다.

| 대상          | 무엇을 보내는가                                                                             |
| ------------- | ------------------------------------------------------------------------------------------- |
| AI 판사 API   | 게시물(금액, 카테고리, 무엇을, 사유), 방 규칙, 잔소리 강도, 배심원 평결과 사유, 피고인 상태 |
| 카카오 로그인 | 로그인 요청과 계정 정보 수신                                                                |
| 웹 푸시       | 브라우저의 푸시 서비스로 알림 전송. 구독 정보는 백엔드가 보관한다                           |

AI 판사 API의 제공사 구성은 `../product/SPEC.md`의 확인 필요 절에 있다. 프론트엔드는 GitHub Pages에 있고 백엔드 호스팅과 첨부 사진 저장 위치는 백엔드와 함께 정한다.

## 게시용 본문

절 구성은 수집하는 항목, 이용 목적, 보관 기간, 제3자 제공, 사용하는 외부 SDK와 호스팅, 문의처, 시행일이다. 시행일 이후에 내용이 바뀌면 개정 이력을 남긴다.

- 이용 목적: 지출 게시물과 배심원 사유는 AI 판결 생성과 방 안 공개에, 무지출 신고와 투표와 댓글은 거지력 점수와 랭킹 계산에, 푸시 구독 정보는 알림 전송에 쓴다
- 보관 기간: 탈퇴 뒤 30일 안에 파기가 제안값이다. 판결이 확정된 게시물은 삭제할 수 없다는 규칙과 탈퇴 처리가 맞물리므로 함께 정한다
- 제3자 제공: AI API 제공사와 카카오, 푸시 서비스로의 전송은 처리 위탁으로 적는다
- 시행일: 게시하는 날을 YYYY-MM-DD 형식으로 적는다
